# Command Center

Personal software factory home repo. Use the `cc` skill to register projects and run saved engineering workflows. Central factory settings live under `repos/` and job records under `jobs/`. Product source and project instructions live in the registered checkouts.

Shared skills are in `skills/`. Read applicable skills on demand. Their shared checklists are in `references/`. See `UPSTREAM.md` for source provenance and `LICENSE.agent-skills` for licensing. Use the Command Center plugin to discover these skills from project sessions.

## Registered repos

See [the repository index](repos/index.md) for project paths and central configuration. Resolve local paths relative to this home repo. Read the selected project's instructions before changes. Save exact requests, configuration snapshots, progress, and evidence in its job directory so a new session can resume.
